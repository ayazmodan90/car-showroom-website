# car-showroom-website
A fully responsive Car Showroom website built using HTML, CSS, JavaScript and PHP with modern UI and user booking features.

## Features

- Responsive homepage
- Car listing section
- About us page
- Contact page
- User booking page
- Login and register pages
- Modern navbar and footer
- Attractive UI design
- Mobile-friendly layout

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## How to Run

1. Download or clone this repository.
2. Copy the project folder into `htdocs` if using XAMPP.
3. Start Apache and MySQL.
4. Open browser and run:

http://localhost/car-showroom-website/
